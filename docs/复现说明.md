# 正式赛复现说明

## 1. 最终版本

最终选定版本为 V83 双分支高分方案，A 榜成绩为 **1.4591**。V69 的 `1.3952170297` 是主分支本地时间验证 MRR，只用于模型选择，不再作为最终提交成绩。

最终输出路由：

- `dataset1.csv`：V69 时间动态图排序主分支；
- `dataset2.csv`：互补预测分支；
- `code/ensemble.py`：逐行验证、按数据集路由并生成 `outputs/result.zip`。

## 2. 环境准备

```bash
sudo apt-get update
sudo apt-get install -y python3.10-dev g++ build-essential libomp-dev
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python code/check_environment.py
```

审核环境：Ubuntu 22.04、CUDA 12.4、Python 3.10、Jittor 1.3.10.0。

## 3. 输入准备

官方数据：

```text
data/track1/dataset1/train.csv
data/track1/dataset1/test.csv
data/track1/dataset2/train.csv
data/track1/dataset2/test.csv
```

或者将官方压缩包保存为 `data/track1_data.zip`。

高分复现还需要将归档的互补预测分支放为：

```text
data/complementary_result.zip
```

其 SHA256 应为：

```text
974582aa2f8f156bbe7f539487450e3e1d7ca75cfaec6027ee2999ad53fdb461
```

## 4. 一键执行

```bash
chmod +x code/run.sh code/run_primary.sh
bash code/run.sh
```

若互补分支不在默认位置：

```bash
COMPLEMENTARY_RESULT_ZIP=/path/to/complementary_result.zip bash code/run.sh
```

脚本依次完成：

1. 检查环境；
2. 训练 V69 主分支；
3. 生成 `outputs/primary_v69.zip`；
4. 对两个预测分支做 CRC、行数、列数和有限值检查；
5. dataset1 选择主分支，dataset2 选择互补分支；
6. 生成 `outputs/result.zip` 和 `outputs/high_score/ensemble_metadata.json`。

只运行主分支：

```bash
bash code/run_primary.sh
```

只运行最终路由：

```bash
python code/ensemble.py \
  --primary_result outputs/primary_v69.zip \
  --complementary_result data/complementary_result.zip \
  --output_dir outputs/high_score \
  --result_zip outputs/result.zip
```

## 5. 预期结果

- `dataset1.csv`：61,051 行；
- `dataset2.csv`：153,420 行；
- 每行恰好 100 个有限浮点分数；
- `result.zip` 根目录只含上述两个 CSV；
- 已归档高分产物 SHA256：`5b9e61fd7ebdb20178b45ae787c2498eaa5ac019081a31ff21ef2475acdc7e6b`。

重新打包时 ZIP 时间戳会改变，所以整包 SHA256 不要求与历史容器完全相同；必须一致的是 `dataset1.csv` 的 `829b6877...cdb7ee5` 和 `dataset2.csv` 的 `a56c257f...f044fb4a`，程序会默认强制核对完整值。

## 6. 故障排查

- 找不到互补分支：检查 `data/complementary_result.zip` 路径和 SHA256；
- 哈希不一致：不要继续提交，先确认使用的是归档高分输入；
- GPU 训练失败：主程序会回退到 CPU `hist`，算法逻辑不变但耗时增加；
- 内存不足：执行 `bash code/run.sh --ranker_chunk_rows 800 --chunk_rows 6000`；
- 最终 ZIP 未生成：查看 `ensemble.py` 报出的具体成员、行号或数值错误；
- 只需验证现有分支时，不必重新训练主模型，直接运行最终路由命令。

## 7. 可复现边界

`main.py` 完整重建时间动态图排序主分支。互补预测分支按固定模型输出归档，`ensemble.py` 对其文件指纹和全部预测矩阵负责校验，并完整复现最终分支选择与打包过程；当前仓库不把该分支的内部训练过程误写为主模型的一部分。
