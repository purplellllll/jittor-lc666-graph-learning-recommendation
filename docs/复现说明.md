# 正式赛复现说明

## 1. 目标

本审核包从官方 Track 1 数据重新训练 dataset1 与 dataset2 的排序器，并生成 `outputs/result.zip`。默认 `final` preset 对应最终 V69 独立方案。

## 2. 环境准备

```bash
sudo apt-get update
sudo apt-get install -y python3.10-dev g++ build-essential libomp-dev
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python code/check_environment.py
```

审核镜像：Ubuntu 22.04、CUDA 12.4、Python 3.10、Jittor 1.3.10.0。

## 3. 数据准备

直接运行时，`code/main.py` 会从脚本内的主办方地址下载并解压数据。若审核环境不允许联网，请预先放置：

```text
data/track1_data.zip
```

或直接准备：

```text
data/track1/dataset1/train.csv
data/track1/dataset1/test.csv
data/track1/dataset2/train.csv
data/track1/dataset2/test.csv
```

## 4. 执行

```bash
chmod +x code/run.sh
bash code/run.sh
```

需要降低内存峰值时，可以减小预测块大小：

```bash
bash code/run.sh --ranker_chunk_rows 800 --chunk_rows 6000
```

## 5. 结果检查

```bash
unzip -l outputs/result.zip
wc -l outputs/dataset1.csv outputs/dataset2.csv
```

预期：

- `dataset1.csv`：61,051 行；
- `dataset2.csv`：153,420 行；
- 每行恰好 100 个浮点分数；
- 每行最小值约为 0、最大值约为 1；
- `result.zip` 根目录只包含上述两个 CSV。

## 6. 关键日志

程序会按顺序输出：读取数据、构建 pair/transition/skip-transition/node 索引、双向 SVD、训练/验证特征、XGBoost 训练、完整历史重建、分块写出结果。元数据写入 `outputs/metadata.json`。

## 7. 故障排查

- GPU 训练失败：程序自动使用 CPU `hist` 重试；结果逻辑不变，但耗时增加。
- 下载失败：手动把官方数据保存为 `data/track1_data.zip`。
- 内存不足：减小 `--ranker_chunk_rows`；特征矩阵训练部分仍建议至少 32 GB 内存。
- XGBoost 版本警告：使用 `requirements.txt` 中固定的 2.1.4。
- 输出 ZIP 未生成：只有 dataset1 与 dataset2 两个 CSV 都存在时才打包。

## 8. 合规声明

程序不访问测试标签。测试候选统计仅基于公开的候选 ID、源节点和时间，不包含真实目标；验证标签来自训练边的严格时间切分。
